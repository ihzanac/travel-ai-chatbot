# Travel AI Chatbot

An AI-powered Travel Assistant Chatbot designed to help users plan and explore travel destinations through an interactive web application.

## 📌 Project Overview

The Travel AI Chatbot provides users with travel-related information through an AI-powered chatbot. Users can ask questions about destinations, hotels, places to visit, travel budgets, and other tourism-related information.

The system also includes an administration panel for managing users and travel-related data.

## ✨ Features

- 🤖 AI-powered Travel Chatbot
- 🗺️ Destination recommendations
- 🏨 Hotel and accommodation information
- 📍 Tourist places and attractions
- 💰 Travel budget assistance
- 👤 User registration and login
- 🔐 Secure authentication
- 🛠️ Admin management panel
- 📊 Travel data management
- 💬 Chat session management
- 📱 Responsive web interface

## 🛠️ Technologies Used
